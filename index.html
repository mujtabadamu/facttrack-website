How it works

No transcription, no waiting for someone else to fact-check it later. It rides along with what you're already watching.

1

Reads existing captions

A content script reads the video's caption track directly — captions must be turned on, nothing is transcribed from audio.

2

Extracts checkable claims

Rolling transcript windows are sent to a small proxy server, which asks an AI model to pull out discrete, checkable claims — statistics, quotes, historical references, current events.

3

Verifies against live sources

Each claim is checked against live web search and returned with a verdict and cited sources — never guessed from memory alone.

4

Streams into the side panel

Claims appear the moment they're spoken; verdicts follow a few seconds later, right next to the video you're watching.

Every claim gets one of four verdicts

No vague "true or false" — and it's tuned to default toward uncertainty rather than risk wrongly calling something false.

✅ Accurate

Matches credible cited sources, no material omission.

⚠️ Missing Context

Technically true, but omits something that changes the meaning.

❌ False

A credible, cited source directly contradicts the claim.

ℹ️ Unverifiable

Not enough evidence to confirm or deny, or credible sources disagree.
